# Temporary forest art study

These exports are temporary original artwork for the movement room's illustrated forest study. They are not team-approved final environment assets or a change to the art directors' specifications. No Don't Starve Together assets were copied or extracted.

The tree and terrain PNGs were generated with the built-in image-generation tool on October 21, 2026. The project consumes the exported PNGs here; generation originals remain outside the repository. PNG exports fall under the repository's existing Git LFS rules. Runtime texture imports are limited to 1024 pixels for square, power-of-two textures.

## Generation prompts

### tree_ink.png

Create one original production game sprite: a single full woodland oak tree as a hand-inked illustrated paper cutout for an elevated-camera 2.5D storybook game. Entire tree fully visible, isolated centered, transparent background with real alpha, square 1024x1024 composition. Irregular rounded layered canopy of muted moss and sage leaves, dark charcoal-brown lively uneven ink contours, delicate crosshatching and parchment grain inside painted shapes, warm bark crooked visible trunk ending at a clear small base. Friendly mysterious fairy-tale woodland, restrained colors, elegant drawn silhouette. Flat 2D illustration facing viewer, no perspective ground plane, no isometric rendered object, no 3D bevels or realistic lighting, no ground, no cast shadow, no scenery, no text, no border. Generous transparent padding around branches and root tips. Tree should fill about 90% height and 85% width. Original artwork with no characters or franchise-specific design. Export as a game-ready transparent PNG. This is a temporary art style test.

### ground_paper.png

Create a seamless square 1024x1024 tileable ground texture for an original hand-illustrated storybook woodland game. Top-down flat texture only, no perspective and no objects. Soft muted moss/sage green grass interwoven with pale olive earth, fine antique paper fibers and delicate sparse charcoal pencil hatch marks, tiny irregular dry grass strokes, subtle mottled hand-painted pigment variation. Fairly uniform overall tone and scale so repeated tiles don't create an obvious checkerboard. All edges seamlessly repeat. Low contrast to keep characters readable. No trees, rocks, flowers, paths, borders, text, cast shadows or lighting gradients. Matte flat 2D ink-and-watercolor game terrain texture, not photorealistic and not 3D.
